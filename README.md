## ✨ Key Highlights

- **🤖 Automatic Capture**: Subscribes to outputs from Antigravity, Codex (Desktop & CLI), Claude Code, and Cursor.
- **⚡ 100% Offline Mode**: Embedded Piper ONNX synthesis runs at **25x real-time** on standard CPUs. Your code and prompts never leave your local machine.
- **🌍 8 Supported Languages & Auto-Detection**: Text language is detected on the fly, seamlessly switching between native speakers for English, Spanish, Chinese, Japanese, Hindi, German, French, and Russian.
- **📊 Smart Table & Code Cards**: Turns Markdown tables into readable visual cards with real-time sentence and word-by-word karaoke highlighting. Click any line to seek instantly.
- **⌨️ Universal Shortcut**: Select any text on your screen (PDF, browser, code editor) and press `Ctrl+Alt+S` (or `Cmd+Shift+S` on macOS) to listen.

## 📦 Installation

### 🪟 Windows (10 / 11)
- **Option 1 (Recommended)**: Download standalone GUI installer:
  👉 **[VoicePlayer-Setup-1.2.0.exe](https://github.com/infostroper-cloud/voice-player/releases/latest/download/VoicePlayer-Setup-1.2.0.exe)**
  *(Automatically installs Python 3.12 quietly if missing on your PC, unpacks, creates shortcuts, and launches).*
- **Option 2 (Portable)**: Download **[VoicePlayer-Installer-1.2.0.zip](https://github.com/infostroper-cloud/voice-player/releases/latest/download/VoicePlayer-Installer-1.2.0.zip)**, extract, and double-click `Install-VoicePlayer.cmd`.

### 🍎 macOS & 🐧 Linux
Run this one-liner in your terminal:
```bash
curl -fsSL https://raw.githubusercontent.com/infostroper-cloud/voice-player/main/install.sh | bash
```
