# VoicePlayer — Голосовой плеер для ИИ (Antigravity, Codex, Claude Code, Cursor)

🌐 **Сайт проекта:** [https://infostroper-cloud.github.io/voice-player/](https://infostroper-cloud.github.io/voice-player/)
⬇️ **Скачать установщик для Windows (v1.2.0):** [VoicePlayer-Installer-1.2.0.zip](https://github.com/infostroper-cloud/voice-player/releases/latest/download/VoicePlayer-Installer-1.2.0.zip)

## Как установить за 30 секунд
1. Скачайте архив **[VoicePlayer-Installer-1.2.0.zip](https://github.com/infostroper-cloud/voice-player/releases/latest/download/VoicePlayer-Installer-1.2.0.zip)** и распакуйте его.
2. Запустите `install-windows.cmd` — на Рабочем столе появится ярлык **VoicePlayer**, а дальше плеер будет обновляться автоматически!
