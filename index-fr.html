Questions fréquentes

VoicePlayer fonctionne-t-il entièrement hors ligne ? +

Oui. Les voix locales Piper et Kokoro tournent sur votre CPU sans internet ; les voix Edge TTS sont aussi disponibles en ligne.

Quels agents IA sont pris en charge ? +

Antigravity, Claude Code, Codex Desktop / CLI, Cursor, DeepSeek Harness, Kimi CLI, Ollama et toute app via API HTTP locale ou presse-papiers.

Comment fonctionne le résumé IA ? +

Dans les paramètres, choisissez OpenAI, DeepSeek, Gemini, Ollama local ou le mode hors ligne.
