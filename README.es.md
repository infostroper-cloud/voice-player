## ✨ Características Principales

- **🤖 Captura Automática**: Se sincroniza con Antigravity, Codex (Desktop y CLI), Claude Code y Cursor mediante ganchos y base de datos compartida.
- **⚡ Modo 100% Offline**: Piper TTS integrado en ONNX funciona a **25× tiempo real** en CPU estándar. Tu código nunca sale de tu equipo.
- **🌍 8 Idiomas y Detección Automática**: Reconocimiento dinámico para cambiar de locutor nativo entre español, inglés, chino, japonés, hindi, alemán, francés y ruso.
- **📊 Tablas Inteligentes y Tarjetas de Código**: Convierte tablas Markdown en tarjetas visuales interactivas con karaoke de lectura en vivo y navegación con un clic.
- **⌨️ Atajo de Teclado Global**: Selecciona texto en pantalla y pulsa `Ctrl+Alt+S` (o `Cmd+Shift+S` en macOS) para escucharlo de inmediato.

## 📦 Instalación

### 🪟 Windows (10 / 11)
- **Opción 1 (Recomendada)**: Descarga el instalador gráfico:  
  👉 **[VoicePlayer-Setup-1.2.0.exe](https://github.com/infostroper-cloud/voice-player/releases/latest/download/VoicePlayer-Setup-1.2.0.exe)**
- **Opción 2 (Portable)**: Descarga **[VoicePlayer-Installer-1.2.0.zip](https://github.com/infostroper-cloud/voice-player/releases/latest/download/VoicePlayer-Installer-1.2.0.zip)**, descomprime y ejecuta `Install-VoicePlayer.cmd`.

### 🍎 macOS y 🐧 Linux
Ejecuta este comando en la terminal:
```bash
curl -fsSL https://raw.githubusercontent.com/infostroper-cloud/voice-player/main/install.sh | bash
```
