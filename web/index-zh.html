常见问题

VoicePlayer 可以完全离线运行吗？ +

可以。本地 Piper 和 Kokoro 语音无需联网即可在 CPU 上运行；联网时也可使用 Edge TTS 神经语音。

支持哪些 AI Agent？ +

支持 Antigravity、Claude Code、Codex Desktop / CLI、Cursor、DeepSeek Harness、Kimi CLI、Ollama，以及通过本地 HTTP API 或剪贴板接入的任何应用。

AI 摘要如何工作？ +

在设置中可自由选择 OpenAI、DeepSeek、Gemini、本地 Ollama 或离线摘要模式。
