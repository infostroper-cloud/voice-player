Frequently Asked Questions

Does VoicePlayer work completely offline? +

Yes. Local Piper and Kokoro voices run directly on your CPU without internet, and neural Edge TTS voices are also available when online.

Which AI agents are supported? +

Antigravity, Claude Code, Codex Desktop / CLI, Cursor, DeepSeek Harness, Kimi CLI, Ollama and any app via local HTTP API or clipboard.

How does AI summary work? +

In Settings you can choose OpenAI, DeepSeek, Gemini, local Ollama or offline summary — it works in any environment.
