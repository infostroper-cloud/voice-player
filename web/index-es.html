Preguntas frecuentes

¿VoicePlayer funciona completamente sin internet? +

Sí. Las voces locales Piper y Kokoro se ejecutan en tu CPU sin conexión; con internet también dispones de Edge TTS.

¿Qué agentes de IA son compatibles? +

Antigravity, Claude Code, Codex Desktop / CLI, Cursor, DeepSeek Harness, Kimi CLI, Ollama y cualquier app mediante HTTP API local o portapapeles.

¿Cómo funciona el resumen con IA? +

En Ajustes puedes elegir OpenAI, DeepSeek, Gemini, Ollama local o resumen sin conexión.
