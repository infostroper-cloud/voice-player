Частые вопросы

Работает ли VoicePlayer полностью офлайн? +

Да. Локальные голоса Piper и Kokoro работают прямо на вашем CPU без интернета, а при подключении к сети доступны также нейросетевые голоса Edge TTS.

Какие AI-агенты поддерживаются? +

Antigravity, Claude Code, Codex Desktop / CLI, Cursor, DeepSeek Harness, Kimi CLI, Ollama и любые программы через локальный HTTP API / буфер обмена.

Как работает AI-саммари? +

В Настройках можно выбрать OpenAI, DeepSeek, Gemini, локальную Ollama или офлайн-выжимку — пересказ сработает в любом окружении.
